# 虚拟选举模拟器

面向教学/演示的**虚拟选举模拟系统**：创建选举 → 配置候选人 → 批量生成海量虚拟选民 → 按可配置的行为模型模拟投票 → 实时计票与可视化 → 审计与导出。

- **零第三方依赖**：后端为 Python 标准库（`http.server` + `sqlite3`），前端为原生 JS（canvas 手绘图表），无需 pip / npm / 数据库安装。
- **高性能**：10 万选民批量生成毫秒级、模拟投票分批落库（每批 5000 票），计票走 SQL 聚合，万级数据无压力。
- **全面**：多选举管理、候选人管理、分选区、投票行为模型、实时趋势、分选区结果、审计日志、CSV 导出、演示数据一键生成。

## 快速启动

> **重要**：不要直接双击 `static/index.html`！必须先启动后端服务。

1. 本机需安装 **Python 3.8+**。
2. 双击 **`start.bat`**（或命令行执行 `python server.py`）。
   - 会弹出黑色控制台窗口，看到"已启动"即成功。
3. 浏览器**自动打开** **http://127.0.0.1:8001**（没自动弹出则手动输入）。

> 换端口：`PORT=9000 python server.py`。不想自动打开浏览器：设置环境变量 `ELECTION_NO_BROWSER=1`。

## 三分钟体验流程

1. 点右上角 **「✨ 一键演示」** → 自动创建含 2 万虚拟选民的演示选举并完成投票，直接看概览图表；
2. 或手动：**新建选举** → 添加 2~10 名候选人 → **开始投票** → 「选民」页生成选民（支持 1 千 ~ 100 万） → 「模拟投票」页调权重/弃权率/无效票率 → 分批模拟，实时看趋势；
3. 结束投票 → 导出结果/投票明细/选民名单 CSV；「审计」页查看全部操作记录。

## 功能清单

| 模块 | 说明 |
|---|---|
| 选举管理 | 创建/编辑/删除，筹备→投票→已结束状态流转，简单多数/绝对多数两种规则 |
| 候选人 | 姓名、阵营/党派、简介、颜色标识，最多 10 名/场，投票开始后锁定 |
| 选民 | 1~100 万批量生成，1~10 选区均匀分布，分页查询/搜索，生成后投票一票制 |
| 模拟投票 | 候选人权重 + 选区偏好偏移 + 随机噪声 + 弃权率 + 无效票率；分批执行实时计票 |
| 计票可视化 | 总票/投票率/有效/无效统计卡，柱状图、环形图、累计趋势折线、分选区结果表 |
| 安全审计 | 全操作审计日志；投票记录含指纹哈希；投票唯一约束防重复 |
| 导出 | 结果 CSV、投票明细 CSV（含指纹）、选民名单 CSV |


## 技术说明

- **数据库**：SQLite WAL 模式，`voters`/`votes` 唯一约束防重复投票，候选人/投票表建索引，计票 `GROUP BY` 聚合。
- **模拟引擎**：纯内存批量生成 + `executemany` 单事务落库；行为模型 = 全局权重 × 选区偏移 × 噪声，弃权/无效票按概率独立判定。
- **性能边界**：100 万选民生成约 1~3 秒，模拟投票分批（默认 5000/批）毫秒级返回；列表页分页加载。

## FAQ

- **改端口冲突了？** 端口被占用会启动失败，换 `PORT=xxxx python server.py`。
- **想重新模拟？** 「模拟投票」页上方或状态栏「↺ 重置票箱」可清空重投。
- **数据在哪？** `data/election.db`，备份 = 复制 `data` 目录。
